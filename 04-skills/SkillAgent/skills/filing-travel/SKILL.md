# Filing travel

1. Search for the airline, hotel or destination.
2. Read the file and note the destination and travel date.
3. Folder: **Travel**.
4. Reason: `<Company>, <destination>, <travel date>`, e.g. `Aurora Air, Calgary to Vancouver, Nov 20, 2026`.
